# 港台翻譯機

將網頁上的香港粵語用語在地化轉換為台灣常用說法，收錄 1200+ 組詞彙，涵蓋生活、飲食、交通、職場等場景。

## 功能

- 自動將香港粵語用語轉換為台灣常用說法
- 台灣一般中文網頁不會被誤轉：詞庫只收粵語專用字與港式用語，兩岸同形異義的詞（如「人工智慧」「關係」「仲裁」）受白名單保護，易混淆的詞僅在偵測到粵語語境時才轉換
- 點擊擴充功能圖示即可快速啟用/停用，無需重整頁面
  - 啟用時：圖示正常顯示
  - 停用時：圖示顯示 ✕ 符號（灰色背景）
- 輸入區塊自動保護，不進行轉換
  - 支援的輸入區塊：文字輸入框、文字區域、下拉選單、可編輯元素
  - 避免干擾使用者輸入內容
- 遇到粗話內容時會以淡化標記取代，不顯示原文
- 所有作業均在瀏覽器本機完成，不收集任何個人資料

## 安裝方式

1. 下載並解壓 `HongKong2Taiwan_Dict.zip`
2. 開啟 Chrome 瀏覽器，前往 `chrome://extensions/`
3. 開啟右上角「開發人員模式」
4. 點擊「載入未封裝項目」，選擇解壓後的資料夾
