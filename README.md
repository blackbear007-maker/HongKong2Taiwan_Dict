# 港台翻譯機

將網頁上的香港粵語用語在地化轉換為台灣常用說法，收錄 1700+ 組詞彙，涵蓋生活、飲食、交通、職場等場景。

## 功能

- 自動將香港粵語用語轉換為台灣常用說法
- 點擊擴充功能圖示即可快速啟用/停用，無需重整頁面
- 遇到粗話內容時會以淡化標記取代，不顯示原文
- 所有作業均在瀏覽器本機完成，不收集任何個人資料

## 安裝方式

1. 下載並解壓 `HongKong2Taiwan_Dict.zip`
2. 開啟 Chrome 瀏覽器，前往 `chrome://extensions/`
3. 開啟右上角「開發人員模式」
4. 點擊「載入未封裝項目」，選擇解壓後的資料夾
